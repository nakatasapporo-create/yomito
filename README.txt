iPadですぐ使う場合
Safariで次のURLを開いてください。
https://yomito-camera-kids-4827.eijisapporo.chatgpt.site
公開版は作成者本人のアクセスに限定されています。

ファイルから設置する場合
3つのファイルを同じフォルダーのままHTTPS対応の静的Webサーバーへアップロードし、Safariでアクセスしてください。
iPadの「ファイル」アプリでHTMLを開くだけでは、カメラ・文字認識・音声が正常に動作しない場合があります。

操作
カメラ：写真を撮る
スピーカー：読み上げる
四角：停止する
右上の設定：アルバム選択、文字の修正、読む速さの変更

文字認識
日本語の横書きの印刷文字向けです。手書き・縦書き・ふりがななどは読み間違える場合があります。
Tesseract.jsと日本語の認識データを外部から読み込むため、インターネット接続が必要です。完全オフライン版ではありません。
写真はブラウザー内で処理し、このアプリのサーバーへ送信・保存しません。
音声には端末の読み上げ機能を使用します。

iPad実機での動作は未確認です。
